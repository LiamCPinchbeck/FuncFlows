Functional normalizing flows: roadmap, skeleton contract, theory & design prompts

A contract and roadmap for building your own skeleton around infinite-dimensional normalizing flows — discrete (NF-iVI) and continuous (f-CNF) — plus prompts to work through the theory and interrogate the reference code. No implementation is prescribed; the contracts and tests are what matter.

P1 arXiv:2411.13277v3 — NF-iVI, discrete functional flows, posterior VI, code public P2 arXiv:2609.03343v1 — f-CNF, continuous functional flows, learned priors, no code Supp supplement of P2

Everything in both papers lives, numerically, in the span of the first M (≤ r) eigenfunctions of C₀. So: state = coefficient vector a ∈ R^r, L² inner product = dot product, ‖a‖²_H = Σ a_i²/λ_i, and the mesh enters only through Φ_grid = [φ_i(x_j)] inside forward models and plots.

BSkeleton contract

Not code — a set of interfaces with invariants and the tests that pin them down. Build it however you like; keep the contracts.

B1 · Interfaces

Reference — Gaussian μ₀ in coefficient space

has
lam[r] (descending), basis(points) → [n_pts, r], sample(n), h_inner(a, b), h_norm2(a), optionally mean[r].
invariants
basis columns L²-orthonormal on a fine grid; E[h_norm2(sample)] = r; Var[a_i] = lam[i].
knobs
r, α, spectral exponent s (λ = σ^{-s}), boundary condition (Neumann / Dirichlet / periodic), dimension (1-D / 2-D), analytic vs numeric eigenbasis, mode ordering and ties.

Transport — any measurable map f: R^r → R^r with tractable log RN

methods
  • push(a) → (f(a), logw) where logw = ln dμ_f/dμ₀ (f(a)).
  • pull(b) → a such that push(a)[0] ≈ b (iterative or ODE-backward; may raise NotImplemented).
  • log_rn_at(b) → ln dμ_f/dμ₀ (b) (default: pull then push; ODE flows do it in one backward solve, Supp Thm 2.1).
invariants
(i) logw equals −ln|det J_f(a)| + ½‖F‖²_H + ⟨a, F⟩_H with J_f the r×r autograd Jacobian — matches det₁ because F has finite rank; (ii) pull(push(a)) ≈ a; (iii) for an affine f and Gaussian μ₀, E_μ₀[logw] equals the closed-form KL between two Gaussians.
families
  • Composite(layers) — P1. Each Layer exposes F(a), logdet(a), constraint_penalty(), and metadata modes (which coefficient indices it touches).
  • ODEFlow(field, T, integrator) — P2. field.h(a, t), field.trace_Dh(a, t); the integrator (Euler / RK4 / adaptive) advances (a, ∫Tr) jointly; pull = same integrator with t: T → 0.
knobs (discrete)
layer types and order, N, per-layer M and mode index set, constraint parameterisation (tanh / softplus / exp), parameter scaling exponent p in u_n = Σ λ_i^p α_i φ_i, init scale, activation.
knobs (ODE)
field family (planar-sum with L terms / Householder-sum / projected Q R(t)(P u + b(t)) / generic MLP in R^M), L, M, T, integrator and n_steps, time-net (depth, width, activation), trace method (analytic rank-1 / autograd M×M / Hutchinson).

Potential — log-likelihood or learned-prior energy on coefficients

methods
__call__(a) → [B], differentiable. Instances: Misfit(forward_model, d, tau) = ½τ‖d − G(a)‖²; LearnedPrior(transport) = −log_rn_at(a); Sum(...).
knobs
forward model, observation points / times, noise-level rule, fine-grid data generation.

Objective — scalar loss from Transport + batch

instances
  • ReverseKL(potential, n_samples) — P1 Alg. 1: E_μ₀[ logw + Φ(f(a)) ].
  • NLL(dataset) — P2 Alg. 1: −mean log_rn_at(u_data).
  • Sinkhorn(forward_model, noise, obs_dataset, eps, batch) — P2 Alg. 2.
  • Conditional(objective, encoder, hypernet) — P1 Alg. 2 wrapper.
invariant
each has a case with a known optimum (Gaussian target ⇒ affine optimum; see T7).

Sampler

instances
pCN(potential, β), SplitPCN(Φ, W, β, k) (Supp §2.4), optional SMC_GM, optional Laplace. All operate in R^r with μ₀ proposals.

Experiment

shape
plain dict of knobs → builds the above → returns {samples, diagnostics}. No framework.

B2 · Tests that define the contract

Write these before the implementations.

  1. Reference: orthonormality; variance per mode; h_norm2 of a sample is O(r), of sample/√λ is O(Σ1/λ) — the Ex. 2.1 / 2.2 point.
  2. Transport.push: logw vs autograd slogdet + H-terms, per layer / per ODE step, r = 30, M = 10.
  3. Transport.pull: round-trip error; for Composite planar / Sylvester compare fixed-point vs Newton inversion; for ODEFlow compare pull(push(a)) at several n_steps.
  4. Euler-ODE ≡ Composite: an ODEFlow with Euler and n_steps = N must produce identical (f(a), logw) to a Composite of N layers I + (T/N)h(·, t_n) with logdet = ln det(I + (T/N)Dh). Then show logw converges as N → ∞ (Supp Thm 2 numerically).
  5. Affine / Gaussian ground truth: one projected layer with analytic R, b ⇒ ReverseKL loss at its floor and zero gradient; NLL on Gaussian data ⇒ minimum equals closed form.
  6. Discretisation invariance: the same trained transport rendered on grids {50, 100, 300} gives identical coefficient statistics and converging grid statistics.
  7. Sampler: pCN on the linear-Gaussian problem reproduces the closed-form posterior; SplitPCN with W ≡ 0 reduces to pCN.

B3 · Extension points to leave open

  • Layer.modes as an arbitrary index set (not just 0..M-1) so you can test which modes need transporting.
  • Reference.lam as a free vector so you can inject non-(I−αΔ)^{-2} spectra, or a learned / estimated spectrum.
  • Transport composable: Composite([ODEFlow(...), SylvesterLayer(...)]) should just work (P2 §3.5 hints at hybrids).
  • Potential composable so Φ − W_θ is one object (P2 eq. 8).
  • Objective takes a Transport, never a specific class.

DTheory prompts

Paste one per turn; attach P1, P2, Supp. Ask for derivations, not code. Use the copy button to grab the prompt text.

T1 — Gaussian measures on Hilbert space, concretelytheory

Let μ₀ = N(0, C₀) on a separable Hilbert space with C₀ trace-class, eigenpairs (λ_i, φ_i). (a) Show μ₀ is the law of Σ √λ_i ξ_i φ_i, ξ_i iid N(0,1), and why trace-class is exactly what makes the series converge in L²(Ω; H_u). (b) Define the Cameron–Martin space H = C₀^{1/2}(H_u) with norm ‖u‖²_H = Σ u_i²/λ_i; show μ₀(H) = 0. (c) State the Cameron–Martin theorem (Bogachev, Gaussian Measures, Thm 2.4.5 — verify the numbering) and derive the RN derivative of the shift u ↦ u + m for m ∈ H, including what ⟨m, u⟩_H means for u ∉ H (the extended pairing / white-noise map). (d) State Feldman–Hájek (Bogachev Thm 2.7.2 — verify) and use the product-measure form (Kakutani's criterion) to show u ↦ 2u yields a singular measure, and more generally u ↦ Σ σ_i u_i φ_i is equivalent to μ₀ iff Σ (σ_i² − 1)² < ∞. (e) Conclude: which perturbations F can a "functional flow" ever use, and why finite rank into H (P1 Thm 2.3) is a sufficient, sledgehammer condition.

T2 — RN derivative of a nonlinear perturbation of the identitytheory

Setting: f(u) = u + F(u), F: H_u → H with finite-dimensional range, Df bijective. (a) In R^r with μ₀ = N(0, Λ), derive d(f_#μ₀)/dμ₀ at the point f(u) via change of variables; write it as |det J_f(u)|⁻¹ exp(A‖F(u)‖²_H + B⟨u, F(u)⟩_H) and determine A, B. (b) Verify on r = 1, f(u) = u + c: the pushforward is N(c, 1). (c) Read Supp §1.2 (proof of Lemma 1, Step 3, Λ_F(u)), and the P1 Thm 2.3 / P2 Thm 5 main-text statements. Identify precisely where the main texts' ⟨u, u − f(u)⟩ (equivalently T = u − f) contradicts the supplement's ⟨u, F⟩ with F = f − u, and which is correct. (d) Explain what det₂ (regularised Fredholm–Carleman, Supp Def. 2) is, why the supplement passes through det₂ and tr DF and then back to det₁, and why for finite-rank F all three determinants are the same finite determinant (Bogachev §6.4, Thm 6.6.7 / Cor 6.6.8 as cited). (e) Show the composite formula for N layers by the chain rule, and explain why the H-terms only involve the total displacement F = f(u) − u while the determinant terms are per layer.

T3 — From discrete layers to an ODE flowtheory

(a) Show that Euler with step τ = T/N applied to dv/dt = h(v,t) produces a P1-type composite Π(I + τ h(·, t_n)). (b) Using ln det(I + τA) = τ tr A + O(τ²‖A‖₁²) for trace-class A, show the log-det sum tends to ∫₀ᵀ Tr Dh(v(t),t) dt (the "instantaneous change of variables", Chen et al. 2018, Thm 1 — verify), giving P2 Thm 5. (c) Reproduce the structure of the Supp Thm-5 proof: which of the four conditions in Def. 4 is used for which bound (C₀⁻¹h bounded ⇒ ‖T_θ^N‖_H and ⟨u, T⟩ bounded; ‖Dh‖₁ bounded ⇒ trace term bounded; Lipschitz ⇒ existence), and why the dominating function g(u) = C₂ exp(C₃‖u‖_{H_u}) is μ₀-integrable (Fernique). (d) Why is ‖C₀⁻¹ h‖_{H_u} < ∞ a stronger requirement than h ∈ H? In coefficient space, what does it say about the decay of the coefficients of h? Relate to the parameter scaling u_n = Σ λ_i^p α_i φ_i: which p gives u_n ∈ H_u, ∈ H, ∈ range(C₀)? (e) Supp Thm 2.1: explain why evaluating W_θ(u) at an arbitrary u needs only one backward ODE solve, and what the trace integral is integrated along.

T4 — Determinants and constraints, layer by layertheory

Work in coefficient space with an orthonormal eigenbasis; a layer touches only coordinates in an index set S, |S| = M. For each of: Householder u − ½ v(⟨v,u⟩ + b), ‖v‖ = 1; projected u + Q R (P u + b); planar u + u_n tanh(⟨w_n,u⟩ + b); Sylvester u + A tanh(B u + b); and the P2 planar-sum vector field h = Σ_{i≤L} u_i σ(⟨v, w_i⟩ + b_i):

(a) write DF as a finite-rank operator and use Sylvester's identity det(I + AB) = det(I_M + BA) (P1 Thm 2.8) to reduce det₁ to an M×M or scalar determinant; for the ODE field write Tr Dh in closed form. (b) State the spectral condition (eigenvalues of DF not in (−∞, −1]) as an explicit inequality on parameters and give the paper's reparameterisation that enforces it (P1 eqs. 2.7, 2.12–2.13; triangular R with bounded diagonal). (c) Householder: prove det = ½ is constant and discuss what this does to the gradient and to expressivity (why P1 needed 24 layers). (d) Sylvester: P1 p.13 says R_B upper-, R_A lower-triangular; the code uses both upper. Which choice makes diag(h') R_B R_A triangular so det = Π(1 + h'_i (R_B R_A)_{ii})? (e) For a generic F restricted to S (e.g. an MLP), what is the cheapest exact logdet and when would Hutchinson's estimator be preferable?

T5 — Losses and their estimatorstheory

(a) Reverse KL: expand D_KL(f_#μ₀ ‖ μ) with dμ/dμ₀ = e^{−Φ}/Z into E_{u~μ₀}[ logw(u) + Φ(f(u)) ] + ln Z; identify constant terms; explain mode-seeking and its consequences for posterior credible intervals. (b) Forward NLL (P2 §3.3): −E_{data} ln dμ_f/dμ₀(u); explain Remark 6 (independence of reference measure) and why this needs f⁻¹. When is reverse KL preferable to forward NLL and vice-versa? (c) Sinkhorn (P2 §3.4): define entropic OT W²_α, why it is differentiable and biased, and why the loss is between ν and η * (SG)_# μ_f (noise convolution) — what happens if you forget to add noise to simulated observations? (d) Monte-Carlo variance: reparameterised gradient of (a) with N samples; argue why N = 30 can suffice for θ with ~10⁴ parameters but the loss value is noisy; propose a control variate. (e) Amortised (P1 Alg. 2): write the objective as an expectation over (x, d) and explain the bias introduced by a finite hypernet capacity; why fine-tuning removes it.

T6 — Discretisation invariance and what breaks ittheory

(a) Restate P1 Defs 2.1–2.4 and Thm 2.9 in coefficient-space terms. (b) Show an implementation storing parameters as eigen-coefficients and evaluating φ_i on the target grid satisfies Def. 2.4, and identify the only grid-dependent objects (forward model, quadrature for from_grid). (c) Show P1 eq. 2.16–2.17 (grid-vector parameters) fails. (d) Quantify the error of using interpolated continuous eigenfunctions on a coarse P1 mesh (P1 code generate_eig.py) vs discrete eigenvectors of M⁻¹K: is ΨᵀKM⁻¹KΨ diagonal? (e) For the ODE flow: is invariance preserved by the integrator? Which of {integrator, n_steps, T} are "model" and which are "numerics"?

T7 — Closed-form cases for unit teststheory

(a) Linear-Gaussian VI: prior N(0, Λ), d = Ga + ε; posterior mean / covariance; show one projected layer on all r coordinates is affine and solve for (R, b) reproducing the posterior exactly; pick the square root making I + R triangular with positive diagonal; compute the loss floor. (b) Gaussian direct data: show P2 §5.1's training family cos 2πx + cos 4πx + 0.3 Σ_{k≤20} ξ_k cos(kπx)/(1+k) is a Gaussian measure — write its mean and covariance in the eigenbasis of μ₀ — and show it is equivalent to μ₀ (finite-rank shift + finite-rank rescaling; use T1(d)). Same for §5.2's ln((sin3θ+5)/3) + … and §5.3's family. (c) Hence: an affine flow attains the NLL optimum on these datasets; compute that optimum (KL between Gaussians) as a test value. (d) Discuss what this implies about the difficulty of P2's experiments and what a genuinely non-Gaussian direct dataset would look like (e.g. level-set or mixture families).

T8 — Learned prior inside Bayestheory

(a) Derive P2 eq. 8 from eq. 7 by the chain rule of RN derivatives. (b) Why does pCN with potential Φ − W_θ target the right posterior? Write the acceptance ratio (Supp Alg. 1). (c) Explain the splitting strategy S-pCN (Supp §2.4): why local W-only steps + a global Φ-acceptance is exact (detailed balance argument), and when it helps. (d) Well-posedness (P2 Thm 9): what is needed of W_θ and of the likelihood; where does the Fernique-type bound exp(W_θ) ≤ C₁ exp(C₂‖u‖) come from?

T9 — What do r, M, N, L, α, s actually control?theory

For each knob give (i) the object it lives in, (ii) the theoretical role, (iii) what you'd expect to see when you sweep it, (iv) an experiment to test that expectation. Knobs: prior rank r; modes touched M (and which modes); number of layers N (discrete) / T, n_steps (ODE); number of planar terms L; α and exponent s in C₀ = (I−αΔ)^{-s}; parameter-scaling exponent p; samples per step; noise level τ. Distinguish "changes the family of measures" from "changes the optimisation".

T10 — Beyond the four layerstheory

Propose three new layer types that satisfy P1 Thm 2.3 / P2 Def. 4 with a closed-form or cheap logdet / trace: (i) coupling layer on a split of the mode set; (ii) rank-M "residual MLP" u + Q g(Pu) with g an MLP and autograd M×M Jacobian; (iii) a Householder-sum ODE field (Supp §4.2, eq. 4.5). For each: verify conditions, give the determinant, note the constraint you must enforce, and estimate cost vs M.

Per-layer determinants

  • Householder: det(I − ½vvᵀ) = 1 − ½‖v‖² = ½; zero gradient from the log-det; rank-1 affine ⇒ many layers needed.
  • Projected: det(I_M + R); the code's R = triu + diag(tanh + ε) gives diag(I+R) ∈ (ε, 2]. Unused tanh is not a bug — the layer is meant to be linear.
  • Planar / planar-sum: 1 + σ'⟨u_n, w_n⟩; for the sum, Tr Dh = Σ_i σ'_i ⟨u_i, w_i⟩ (Supp §4.1 Parts 1–3).
  • Sylvester (Q4): both upper-triangular ⇒ R_B R_A upper-triangular with diagonal diag(R_A) (since diag(R_B) = 1) ⇒ logdet = Σ ln(1 + h'_i diag(R_A)_i); matches common_flows.py:133–138. P1 p.13's "R_A lower-triangular" is inconsistent with its own determinant claim. Same trick for Q21 with an L×L determinant: det(I + τ U diag(σ') Wᵀ) = det(I_L + τ diag(σ') Wᵀ U).
